# Simple Interest Calculator

A simple bash script to calculate simple interest given principal, annual rate of interest, and time period in years.

## Project Overview

This repository (`cal-567`) contains a lightweight command-line calculator written in Bash to compute simple interest based on user inputs.

## Input Parameters
* **p**: Principal amount
* **t**: Time period in years
* **r**: Annual rate of interest

## Output
* **simple interest**: Calculated using the formula `(p * t * r) / 100`
